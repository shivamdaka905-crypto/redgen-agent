Your agent runs at the Space URL. Add variables in **Settings -> Variables and secrets**:
`LLM_API_KEY`, `IMAGE_API_KEY`, `YOUTUBE_API_KEY`, `WHATSAPP_TOKEN`, `WHATSAPP_PHONE_ID`.

Free CPU Spaces sleep after inactivity; the first request after a sleep takes ~30 seconds.
